# DockPilot 图标设计哲学 — "满载领航"（Full Cargo Ahead）

## 核心意象

Docker 的世界由集装箱写成，DockPilot 的图标便让一艘货轮满载驶来：
船体是"码头（Dock）"，舵在船长手中，"领航（Pilot）"的是屏幕前的你。
顶层一只立体宝蓝箱是画面的主角——它是你正在调度的那只容器；
底舱深蓝与青绿两色三箱整齐列队，是泊位上井然的服务群；
每一只箱的正面都压出三道瓦楞门槽——暗槽与受光棱线成对出现，
这是海运集装箱与生俱来的识别码，也让箱体摆脱色块的呆板；
右上一枚青色星光，是部署成功那一刻的信号弹。
熟悉容器技术的人会心一笑，不熟悉的人看到的是一艘干净的平底货船。

## 空间与形态

图形由四层结构叠成，自后向前：水影椭圆 → 船体 → 集装箱 → 星光。
甲板线几乎是一条自左向右缓缓抬升的直线，在船头处收成一道利落的斜切舷弧；
船底平直、两端圆收，一只扁椭圆水影贴着船底向两侧探出，船便"泊"在了水面上。
集装箱行以白色细描边与船体互相分离——这条白线是整幅图的呼吸感所在：
它让箱体"坐进"船舱而不是"粘在"船上，也让船舷粗描边得以从箱前横越而过，
形成栏杆在货箱之前的层次。所有拐角统一圆角半径，如同同一套模具冲压出的箱件。

## 色彩与材质

四色体系，与海运集装箱的原色同源：

- **墨蓝 #0A2E55**：船体描边、底舱深蓝箱、水影椭圆——全图的骨架与最重的体量；
- **宝蓝 #0B4C8C**：顶层箱正面，配 #072A50 的左上侧面构成 3D 体块，是视线的第一落点；
- **青绿 #0CC7BD**：底舱两只箱体，是画面中唯一的暖色张力，呼应 Docker 鲸鱼的青；
- **亮青 #27DDF5**：四角星光，全图最亮的一点，只在成功时出现。

箱面的瓦楞纹以"暗槽 + 棱线"成对竖线表达：槽用各自底色的深化色（深蓝箱 #051C36、
青绿箱 #08998F、宝蓝箱 #07325E），棱线用提亮色（#2A5480 / #52E0D7 / #2F6DAD），
一道凹陷一道受光，平面矢量便有了冲压钢板的凹凸。竖线两端圆头、距箱缘留出圆角的呼吸位，
在 48px 以上纹理可辨，在 32px 以下自然融为体块——细节有退场机制，小尺寸永不糊成一团。

船舱内部以一道 #C9D3DD 的浅灰月牙贴着船头内壁与船底铺开，给白色船体一点
受光的体积感；应用图标底板为自上而下的冰白渐变（#FFFFFF → #EFF4F9），
四角 224px 圆角，让浅色图标在深浅两色桌面上都有一圈干净的轮廓。

## 尺度与节律

图形按 72% 的宽度居中于图标底板。结构在 16px 的任务栏上依然成立：
一道深蓝船线、三只方箱、一点星光，即是全部——细节服务于大尺寸，
结构服务于小尺寸。星光的四角由同一组贝塞尔曲线镜像而成，收锋细而不弱，
在 512px 的应用商店里锋利如信号弹，在 24px 里仍是一粒可辨的亮点。

## 工艺标准

每一处圆角、每一根线条的端帽、每一次渐变的落点，都应当像出自一位
对航海图与徽章学同样精通的匠人之手——反复推敲、别无侥幸。
宁可删去十个装饰，也不放过一处含糊。
