# DockPilot 图标设计哲学 — "沉稳领航"（Steady Helm）

## 核心意象

DockPilot 的图标由两个词根熔铸而成：**舵轮（Helm）**与**集装箱（Container）**。
舵轮是"领航员"的古老符号——八根辐条、一圈护栏，代表对航向的绝对掌控；
集装箱是 Docker 时代的通用语——波纹门板、方正体量，代表被驯服的货物。
让集装箱成为舵轮的轴心：**你掌舵，货物随行**。熟悉容器技术的人会心一笑，
不熟悉的人看到的是一件干净的几何徽章。

## 空间与形态

单一居中的图形，占据画布约七成，四周留出沉静的深色水面。
所有线条均为几何完美的圆与直线：外环半径、辐条起止、圆角半径全部经过精确计算，
如同港池中按航道精确泊位的船。辐条延伸出环外，形成舵柄的"把手"，
这是传统船舵的功能性特征，也是图标在小尺寸下仍可辨识的关键结构。

## 色彩与材质

三段式色彩层级，与 DockPilot 应用本体同源：

- **底**：深海航夜的蓝黑（#131F33 → #0A0F1A 对角渐变），中央有一圈极微弱的翡翠辉光，如灯塔在雾中的光晕；
- **环**：翡翠绿渐变（#6EE7B7 → #059669），从左上受光面转向右下阴影面，赋予金属环体积感；
- **心**：集装箱采用冰白色（#FFFFFF → #D7E2EE），是全图最亮的点——视线第一落点，波纹门槽以 15% 透明度的深色细线暗示，克制而不喧哗。

## 尺度与节律

图标必须在 16px 的任务栏与 512px 的应用商店中同样成立：
远看是"深色底上一枚带白心的绿色舵轮"的三段剪影，近看才有波纹门板与舵柄圆头的细节。
一切细节服务于大尺寸，一切结构服务于小尺寸。

## 工艺标准

每一处圆角、每一根线条的端帽、每一次渐变的落点，都应当像出自一位
对航海图与徽章学同样精通的匠人之手——反复推敲、别无侥幸。
宁可删去十个装饰，也不放过一处含糊。
